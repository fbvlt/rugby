01 Démarrage rapide

L'application fonctionne directement dans le navigateur — aucune installation requise. Toutes les données sont sauvegardées automatiquement sur l'appareil.

📋 Matchs
🏉 Compo
🔄 Banc
📊 Stats

La navigation principale comporte 4 onglets. Le bouton ⚙️ en haut à droite du logo ouvre la configuration sans quitter les onglets.

En 3 minutes chrono

  • 1Ouvrez ⚙️ → chargez votre Google Sheet avec la liste des joueurs.
  • 2Donnez un nom au tournoi, choisissez le format XV X ou VII.
  • 3Onglet 📋 Matchs → + Match pour créer le premier match.
  • 4Onglet 🏉 Compo → ⚡ Sélection auto pour remplir l'équipe.
  • 5Appuyez sur ▶ Start — l'appli trace le temps de jeu en temps réel.
⚙️

02 Configuration

Connexion au Google Sheet

📋
Colonne A : Nom du joueur
Colonne B : Postes séparés par des virgules
Exemple : Jean Dupont | pilier, talonneur

Postes reconnus : pilier, talonneur, 2ème ligne, flanker, numéro 8, demi de mêlée, demi d'ouverture, centre, ailier, arrière. Les variantes anglaises (prop, hooker, wing…) sont aussi acceptées.
  • 1Dans Google Sheets : Partager → "Tout le monde avec le lien" → Lecteur.
  • 2Copiez l'URL et collez-la dans le champ URL d'export CSV.
  • 3Tapez ⬇️ Charger les joueurs. La liste apparaît en dessous.

Format et tournoi

Choisissez XV, X ou VII comme format par défaut. Les durées de mi-temps sont prédéfinies (40 / 25 / 7 min) mais modifiables par match. Les nouveaux matchs héritent automatiquement de la durée du match précédent.

Joueurs absents

Dans la carte Absents du tournoi, tapez un nom pour le marquer absent 🚫. Il disparaît de la composition, du banc et de la sélection automatique pour toute la durée du tournoi. Tapez à nouveau pour le réactiver.

Sauvegarde

📤
Export JSON
Sauvegarde complète : joueurs, matchs, stats. À faire après chaque tournoi.
📥
Import JSON
Restaure une sauvegarde ou transfère les données vers un autre appareil.
⚠️
Les données sont dans le navigateur. Ne videz pas le cache entre les matchs. Exportez en JSON après chaque tournoi.

03 Calendrier de la journée

L'onglet 📋 Matchs fonctionne comme un planning complet de la journée. Il contient deux types d'items : les matchs et les pauses.

Créer un match

  • 1Bouton + Match → saisissez le nom (ex : Match 1, vs Biarritz).
  • 2Saisissez l'heure de début (HH:MM) — optionnel, peut être ajouté ou modifié plus tard.
  • 3Le match est créé avec le format et la durée du match précédent. L'onglet Matchs reste actif.

Créer une pause Nouveau

Les pauses représentent les périodes où votre équipe ne joue pas (matchs adverses, déjeuner, déplacement…).

  • 1Bouton ⏸ Pause → saisissez la description.
  • 2Heure de début (optionnel) et durée estimée en minutes.

Heure de début

Chaque item (match ou pause) affiche un bouton 🕐 heure ou + heure. Tapez-le pour saisir ou modifier l'heure au format HH:MM. L'heure est purement indicative — elle ne déclenche rien automatiquement.

Réorganiser l'ordre Nouveau

  • 1Appuyez sur ⇅ Trier — les poignées ☰ apparaissent à gauche de chaque item, les boutons Supprimer disparaissent.
  • 2Maintenez appuyé sur une poignée ☰ et faites glisser l'item vers sa nouvelle position. Une ligne orange indique l'emplacement cible.
  • 3Relâchez — l'ordre est sauvegardé immédiatement.
  • 4Appuyez à nouveau sur ⇅ Trier pour quitter le mode de tri et retrouver les boutons habituels.
💡
En mode tri, les matchs ne sont plus cliquables — cela évite les sélections accidentelles lors du glisser-déposer.

Sélectionner un match actif

Tapez un match dans la liste pour l'activer. Le match actif affiche le badge ACTIF. Le chrono se réinitialise pour ce match. Les pauses ne sont pas sélectionnables.

Supprimer un item

Bouton 🗑 à droite de chaque item (visible hors mode tri).

04 Composition de l'équipe

Choisir un joueur pour un poste

  • 1Tapez une case de poste → le sélecteur s'ouvre par le bas.
  • 2Les joueurs qualifiés pour ce poste apparaissent en premier avec le badge ✓ POSTE.
  • 3Chaque joueur affiche ses entrées (match / tournoi) et son temps de jeu. Les joueurs absents et les joueurs déjà sur le terrain n'apparaissent pas.

Code couleur des cases

Gris — poste vide
Vert — joueur attribué
Vert pulsant — joueur en jeu, chrono actif (point vert animé)

⚡ Sélection automatique

Le bouton ⚡ Sélection auto remplit tous les postes en deux passes :

  • 1Passe naturelle : chaque poste est attribué au joueur disponible le moins joué au tournoi qui peut y jouer naturellement.
  • 2Dépannage : les postes restants sont comblés en priorisant le joueur ayant le moins joué à ce poste précis en dépannage, puis le moins joué au total.
💡
Une confirmation indique combien de postes seront remplis. Les joueurs absents sont exclus. Les postes déjà remplis sont remplacés.

🔁 Compo 2ème mi-temps

Le bouton 🔁 Compo 2ème mi-temps apparaît uniquement à la pause de mi-temps, et uniquement si le match n'est pas en mode "sans mi-temps". Il applique la même logique que la sélection auto, mais conserve les joueurs sur le terrain depuis ≤ 1 minute (ceux qui viennent d'entrer). Une confirmation liste les joueurs conservés avant d'appliquer.

🔀 Swap entre deux joueurs

  • 1Tapez 🔀 Swap joueurs → mode swap activé (cases bleues au clic).
  • 2Tapez le premier joueur (surbrillance bleue), puis le second → échange immédiat.
  • 3Tapez ✕ Quitter swap pour revenir au mode normal.

Retirer un joueur

Tapez une case remplie → ouvrez le sélecteur → bouton 🗑 Retirer le joueur en bas.

05 Chronomètre

Le chronomètre est affiché en haut de l'onglet 🏉 Compo. Il décompte depuis la durée de mi-temps définie.

1ÈRE MI-TEMPS
18:42
⏸ Pause 🔔 Mi-Temps

Boutons selon la phase de jeu Mis à jour

▶
Start
Lance le décompte. Visible uniquement quand le chrono est arrêté en 1ère ou 2ème mi-temps.
⏸
Pause
Stoppe le décompte et enregistre les temps. Réappuyer sur Start pour reprendre.
🔔
Mi-Temps
Visible uniquement en 1ère mi-temps. Passe en pause de mi-temps, remet le chrono à zéro.
🏁
Fin de match
Remplace "Mi-Temps" dès que la 2ème mi-temps commence. Visible dès le départ en mode sans mi-temps.
▶
2ème mi-temps
Apparaît uniquement à la pause de mi-temps. Lance le décompte de la 2ème période.
↺
Reset
Remet le chrono à zéro. Les temps de jeu déjà enregistrés sont conservés.
🔘
Sans mi-temps Nouveau
Interrupteur dans les réglages du chrono. Supprime la mi-temps : un seul décompte, le bouton 🏁 Fin de match est présent dès le départ.

Temps additionnel Nouveau

Quand le décompte atteint 0:00, le chrono ne s'arrête pas — il passe en temps additionnel affiché en +MM:SS rouge animé avec la mention TEMPS ADDITIONNEL. Le temps de jeu des joueurs continue à s'accumuler. Le bouton 🔔 Mi-Temps devient 🔔 Siffler pour signaler la fin manuellement.

Réglages du chrono

Deux champs sont disponibles dans le bloc chrono :

  • ·Min/mi-temps — durée de chaque mi-temps. La modifier met automatiquement à jour l'intervalle de suggestion à la moitié de cette valeur.
  • ·Propos. chgt (min) — intervalle avant la prochaine suggestion de changements (0 = désactivé). Voir section 07.
  • ·Sans mi-temps — interrupteur orange. Quand activé, supprime toute la logique de mi-temps : chrono unique, bouton 🏁 Fin de match visible dès le départ, pas de compo 2ème mi-temps.

Code couleur du chrono

Vert — chrono en cours
Bleu — pause de mi-temps
Rouge animé — temps additionnel
Rouge fixe — match terminé
ℹ️
Le temps de jeu s'accumule uniquement quand un joueur est sur un poste ET que le chrono tourne. Placer un joueur avec le chrono à l'arrêt ne déclenche pas de comptage.

06 Banc & remplacements

L'onglet 🔄 Banc liste tous les joueurs disponibles non sur le terrain, triés du moins joué au plus joué au tournoi. Les 3 premiers (les plus prioritaires à entrer) sont mis en valeur en orange.

Effectuer un remplacement

  • 1Tapez le remplaçant dans la liste → il se sélectionne (bordure orange).
  • 2La grille du terrain s'affiche en dessous.
  • 3Les postes compatibles pulsent en orange avec le temps depuis le dernier changement en grand.
  • 4Les postes incompatibles (dépannage) restent grisés en pointillés, cliquables si nécessaire.
  • 5Tapez le poste → substitution immédiate.
💡
Le temps affiché en grand sur chaque case est la durée depuis le dernier changement à ce poste — votre outil principal pour décider qui doit sortir.

Annuler une sélection

Tapez à nouveau le remplaçant sélectionné, ou le bouton ✕ Annuler la sélection.

ℹ️
Lors d'une substitution, le temps du sortant est automatiquement clôturé avec le bon poste, et le remplaçant commence à être chronométré si le chrono est actif.
💡

07 Suggestions de changements Nouveau

L'appli peut proposer automatiquement des changements à intervalles réguliers, en se basant sur les temps de jeu au tournoi.

Paramétrage

Le champ Propos. chgt (min) dans le bloc chrono définit l'intervalle en minutes entre deux propositions. 0 = désactivé. La valeur par défaut est la moitié de la durée d'une mi-temps, et se met à jour automatiquement quand vous changez la durée de mi-temps.

Logique de sélection

  • ·Les remplaçants proposés sont ceux avec le moins de temps de jeu au tournoi (la moitié du banc, arrondis au supérieur).
  • ·Le joueur sortant est celui avec le plus de temps de jeu au poste naturel du remplaçant entrant.
  • ·Si aucun poste naturel n'est disponible, le joueur le plus joué du terrain est proposé en dépannage (marqué dépannage).

Panneau de suggestions Mis à jour

Quand l'intervalle est atteint, un panneau bleu apparaît dans le bloc chrono :

  • ·Chaque ligne affiche le sortant → entrant avec le numéro et nom du poste.
  • ·Bouton ✓ Valider sur chaque ligne — valide ce changement individuel et marque la ligne en vert. Le panneau reste ouvert pour valider les autres.
  • ·Vous pouvez valider plusieurs changements dans n'importe quel ordre avant de fermer.
  • ·Bouton ✕ Fermer — ferme le panneau et demande la prochaine durée avant une nouvelle proposition.

Fermeture et replanification

À la fermeture du panneau, un champ permet de saisir la durée avant la prochaine proposition (en minutes). Si cette valeur est supérieure ou égale au temps restant dans la mi-temps, aucune nouvelle suggestion n'est planifiée. Saisir 0 désactive aussi les suggestions.

💡
Ignorer toutes les suggestions sans rien valider est possible — fermez simplement le panneau. Les suggestions ne bloquent jamais le chrono ni les autres actions.

08 Statistiques

L'onglet 📊 Stats offre trois niveaux d'analyse, mis à jour en temps réel pendant le chrono.

Résumé (4 chiffres clés)

📋
Matchs
Nombre total de matchs du tournoi.
👥
Joueurs
Effectif total chargé (absents inclus).
🏉
Match actuel
Postes remplis / total, format (XV/X/VII).
⚠️
N'ont pas joué
Joueurs avec 0 seconde au tournoi.

Tableau temps de jeu & entrées

Pour chaque joueur, trié par temps total décroissant au tournoi. Un point vert animé signale les joueurs actuellement sur le terrain (temps mis à jour en direct).

Tableau temps par poste

Cumul du temps à chaque type de poste sur le tournoi. La colonne % Naturel indique la proportion de temps jouée aux postes naturels :

Vert (≥ 80%) — joue principalement à son poste naturel
Jaune (50–79%) — utilisation mixte
Orange (< 50%) — surtout en dépannage

Les colonnes de poste sont colorées en vert pour les postes naturels, en orange + badge dép. pour le dépannage.

Export CSV

Un outil séparé (rugby-json-to-csv.html) convertit l'export JSON en 6 feuilles CSV : joueurs, calendrier, temps de jeu, temps par poste, détail par match, compositions.

09 Workflows de match

Début de tournoi

  • 1Chargez le Google Sheet → vérifiez la liste des joueurs.
  • 2Marquez les absents dans ⚙️ Config.
  • 3Choisissez le format et le nom du tournoi.
  • 4Créez les matchs et les pauses de la journée dans 📋 Matchs avec leurs heures de début. Réorganisez si besoin avec ⇅ Trier.

Avant chaque match

  • 1Sélectionnez le match dans la liste → l'appli bascule sur Compo.
  • 2Utilisez ⚡ Sélection auto — les moins joués du tournoi sont prioritaires.
  • 3Vérifiez la durée de mi-temps et l'intervalle de suggestion.

Pendant un match

  • 1Appuyez sur ▶ Start au coup d'envoi.
  • 2Changements : onglet 🔄 Banc → sélectionnez le remplaçant → tapez le poste.
  • 3Swap : 🔀 Swap joueurs dans l'onglet Compo.
  • 4Avec mi-temps : 🔔 Mi-Temps → optionnellement 🔁 Compo 2ème mi-temps → ▶ 2ème mi-temps.
  • 5Fin du match : 🏁 Fin de match (ou laisser le temps additionnel s'écouler puis siffler). Sans mi-temps : ce bouton est présent dès le début.

Entre deux matchs

  • 1Consultez 📊 Stats pour voir qui n'a pas joué.
  • 2Sélectionnez le match suivant dans la liste.
  • 3Utilisez ⚡ Sélection auto — l'algorithme privilégie automatiquement les moins joués.

Fin de tournoi

  • 1Consultez les stats pour bilan complet.
  • 2Exportez les données : ⚙️ Config → Exporter JSON.
  • 3Bouton 🔄 Nouveau tournoi — confirme, propose un export JSON, puis supprime tous les matchs et remet les stats à zéro.
⚠️
Nouveau tournoi = suppression complète. Tous les matchs sont effacés et les stats remises à zéro. Un export JSON est proposé avant la suppression.

10 Installation & données

Installer sur Android (recommandé)

  • 1Ouvrez l'appli dans Chrome sur Android.
  • 2Menu ⋮ → "Ajouter à l'écran d'accueil".
  • 3L'appli s'ouvre désormais en plein écran comme une vraie app native.

Partager avec d'autres coachs

L'appli est un fichier HTML autonome. Envoyez-le par WhatsApp ou e-mail — il s'ouvre directement dans le navigateur. Pour déployer en ligne : netlify.com/drop (glissez le fichier → URL permanente gratuite en 2 min).

Bonnes pratiques de sauvegarde

Exportez en JSON après chaque tournoi
Ne videz pas les données du navigateur entre les matchs
Importez le JSON sur le nouvel appareil pour migrer
ℹ️
L'appli fonctionne hors-ligne une fois chargée. Seul le chargement du Google Sheet nécessite une connexion internet.
